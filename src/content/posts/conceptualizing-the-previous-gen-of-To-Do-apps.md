大概就是这样，我看到了一篇少数派文章：[App+1 | 我做了一个专为「P 人」和 ADHD 设计的精力管理 App](https://sspai.com/post/115400)

给我也看馋了。我本人确实是个 INFP， ~~虽然感觉大多数时候我才是需要被疗护的那个😭💀~~ ，但是我对于忘记事情这方面确实是挺擅长的（当然还有咕咕咕）。我目前正在使用的是 Microsoft ToDo，鉴于它的云同步和设计还算简易（不易让我分心），于是便用的还行……？

不过确实，所有软件都有缺点。

## 痛点

Microsoft Todo 的痛点不算很多，但也不少了。

- **分类何意味。** 包括「工作」「已计划」这些 *智能列表* 我只能看得懂几个。是否加入工作我更是没看懂。
- **列表分类有点没用。** mstodo 的分类是 Categories 的互斥，要创建不互斥的 Tags 就必须到隔壁 Outlook 创建，而且它是邮件 / Todo 项通用的。而我需要的分类就是分明的，或者另一种方式来说，我其实根本不需要分类——徒增心智负担还要设定颜色啥啥的在我这种形式主义的人面前很容易浪费个把小时 Set up 这种东西。
- **仪式感太强了。** 我用 Todo 本来也是想着记记作业什么的。但他仪式感太强我都懒得打开。
- **有些过度设计。** 像「过期时间」和「提醒我」感觉就很像。
- **感觉还是太重了。** 虽然云同步很好不过我现在不是特别喜欢大厂绑定的东西的说，而且鉴于微软砍刀部的尿性总让我感觉明天就会宣布它取消支持。
- **循环任务取消不了。** 像 OMI 写作我就设计成了每日循环任务。不过就它更新频率看哈哈哈哈

## 原软件优点与愿景

说了这么多 MSTodo 其实还是有自己的优势在的。让我们来细数一下我日用的 Todo 软件应该做到的点。

- 首先我是 P 人，所以我想要的 Todo 软件不会有很多设置、很多花里胡哨的元素，也没有很多支持自定义的地方（ ~~拜托我还要自己写，总不能一把梭哈歪脖口顶吧~~ ）
- 更好的循环任务设计。我可能会给它专门开一个 Tab 用日历或者像 GitHub 热力图一样的图片，后面跟今日循环任务。
- 更好的分类设计。参考促使我做这个软件的灵感来源，我想要的是它能够自动判断任务重要性、急迫性、工作平台等属性，不过大概率不会很好做……
- 今日任务推荐。考虑到学生群体工作日能完成的 Todo 不多，加上我个人家庭电子设备配额，可能会做特调？我不确定。总之就是结合上面一个配置要工作日、节假日还是随时能做的属性，然后根据算法结合属性与今日时间分配推算出我今日要做的事情有哪些……不过好像也挺复杂。
- 多端与云同步。云同步估计不太好弄 ~~除非谁送我台服务器~~ 不然我只能写个 WebDav 的同步设定然后让你自己跑服务。多端的话倒很好想，Flutter 应该是很成熟的技术栈了，Web 也行不过我不是很想用 Web。
