> **The Echo 回响倚音**系列第ε篇。不知道写给谁看，也许你会看到。

你好，这里是 MacrosMeng。欢迎来到 *The Echo 回响倚音* 系列。

我本不想介绍这个名字，因为这会赋予它存在，赋予它意义。它一旦有了独立于虚空中的存在，我想在我的思想中，大概很快就会分崩离析。

但是那有什么大不了的。分崩离析，我见得多了，只要再取一个新名字，就可以了。新名字好取，只是些「中二」抑或是「哲学的抽象」的代名词，无伤大雅。

Echo，回响。回响存在于任何地方。那些我们曾对宇宙说过的话，对自己，对他人的赞扬，抑或是谩骂，所产生的波——声波，或者「声粒子」，如果你对波粒二象性有狂热的喜爱——我宁愿相信宇宙中的真空，并不是真「空」——而是有被尚未发现的造物主所遗漏的几个，几十个，lim(n->Inf) n 个微观粒子——所传播，到达有穷而无界的宇宙的各个角落。彼即回响，宇宙的回响，心灵的回响。

而中文名，回响倚音，比起直译多了倚音这两个字。有时候其实很是悲伤，感觉全然是为了为他人做陪衬而生的。抽奖权当增大分母，哈哈。但我却宁愿去做倚音。前倚音，后倚音……大概这跟我的人格很类似吧。我是很渴望了解他人的一个人，我也很想要去真正帮助那些困顿于自己的心锁之中无法自拔的人。但谁知道呢，我从来没有过这种经历，而大概也没什么人来看望我，看望这篇文章罢。但又是真正令我苦恼的，我也会觉得那些安慰我的人只是想让我觉得我有「存在」——物理意义上的 Existence——而不是真正的触碰心灵的对话。而我由此得出我大概是有点精神疾病了，尽管我从未看过心理医生（笑），多么病态的心理。而那些我所知晓的有真实心理疾病的患者，却又都是，都也是这么想的。看来人和人之间已然隔了一层可悲的厚障壁了。

而后又说回来，我写这段文字，这篇文章，开启这个我偷闲而敲下来的所有内容，其实都没有什么人看罢了，其实都没有什么重要罢了。但是，我无疑是孤独的。能力不足以完成一篇旷世巨作或是 Code 出一个举世闻名的项目的我大概也只能写写随笔，批斗一下我所愤怒的所感伤的所一切欲想抒发的罢。我想而又想，这算不算一种虚无主义呢？觉得这一切都会消失？它固然会消失。天下大势，分久必合，合久必分。然而你我都没有能力成为死后能够重若泰山的一般人物罢了。然而我并不虚无。我实质上是很乐观的尽管你读——或是就没有人读——而我也一样的，觉得这段文字实质上有很浓重的悲观色彩而已，而事物都有两面性，谁说一个整天跟个傻逼一样游荡在学校里所不知道做些什么无意义的事的人一定是悲观的，一定是乐观的呢。而我恰然就是这种人啊。我只是被赋予了存在的语义的另一个实体，与你，与 TA，无何异同。

哲学和自然科学，或称物理，于叙事是很好的，却也是我不曾深入的。我深入过数学：学了一点限于卖弄的微积分，然而这并无何用，对于初三的我来说，只是一个玩物罢了；我深入过计算机科学，却也只会 Python 的一点可怜的知识，不足以支撑起庞大的构想。然而我庞大的构想恰恰是最多的，所以未竟事业的伤痕自然就是痛苦之根源了。我现在写写浅层思考的文章，也正是我不能那么深层去思考表达的表现而已。谁不会深层的思考呢？只是这些思绪易逝，而又无法被表达成文字的浅显之意义罢。而这又是一个不同的话题，然即性认同。我自认为不是性少数群体的，而自认为也就够了，毕竟性认同的方面，哪个是他人强加的标签呢？大多也就是玩梗而已的「给」罢了（笑）。但是，我所处的社区，集学生、开发者、等等于一体了。所发生的事便十分易于解释了。而它们的离去，在许多普通学生中的离去，显得尤为突出，这也不过是因为它们只是特殊群体中的极特殊群体，恰好也是我认识的人中所认识的圈环着圈的人物罢了。但这不就仅仅是罢了——我为它们的离去而悲伤，而谁又不会感到悲伤。这一切本可以发生在那些恶人身上，它们却自发选择了离去——恰恰的又不是自发的。

也许我该少思考一点，把所谓的精力所放在「学生的正业」上。但我恰恰却是最「不听话的」那个。我喜爱又厌恶这个角色。喜爱，因为我能反抗那些比我强大的力量，尽管没有什么实质性的用处，而痛苦的是我自己，我却乐此不疲罢了；厌恶，则是我的力量太过于弱小，而真正受苦的其他人，却都甘愿俯首接收那病态的教育罢了。

但这世上又有什么是非病态的呢。我是病态的，我特立独行，我……我不知道。很难受的，我做不了什么。恐怕这也是「病」之根源之一罢。但我仍深爱这世界，这病态的世界。试问，哪个中国的学生没想过以一种任意的方式离去呢？因为我还想帮助别人，这怕也就是我仅存的心脏中的一点好意了。然而恶人必定是多数的。所以我才是病态的。宇宙中没有乌托邦。

既就是文。
