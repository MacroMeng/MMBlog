## History

你好，欢迎来到第三代 MMSite。

MMSite 经历了许多波折。起初，我准备使用 Hugo 构建这个博客。但由于 Hugo 在国内连接性不佳，从而没有成功。

于是遂用相似的 Hexo 构建起来，为了省去记忆（当时对我来说的）意义不明的缩写，我甚至写了一个 Hexo 小玩具 UI 发到了 GitHub 上。当时真是精力充沛啊（感叹）。::github{repo="MacroMeng/HexoGUI"}

等到 @MKStoler 帮我折腾 OhMyIWB 那段时间，（好像已经很多年了呢……）我开始折腾 Astro 博客。这便是第二代 MMSite。基本上来说，这是个字母哥维护的 Astro 博客主题，从 Astro 市场随便找的一个。标题这种用 JetBrains Mono，正文就是 `sans-serif` 了。甚至调色板也很多，一眼就看到了 Catppuccin （好吃😋👍）用上了（现在主题的代码配色方案也是 Catppuccin）。

然后我就在 GitHub 刷 Discover 时看到了这个主题。也是基于 Astro 的一个 M3E 主题，是否 Expressive 我还不敢确信，毕竟看着 Vibe 含量挺高的（）但是比上一个好看，遂用上。

这就是 MMSite 完整发展史了，祝你有好的一天。
