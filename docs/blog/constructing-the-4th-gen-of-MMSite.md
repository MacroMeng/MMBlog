# 构建第 4 代 MMSite

你是说 MMSite 已经到第四代了？

好吧我对时间的感觉越来越迟钝了，小学 6 年的漫长和初中两年多完全比不了。（~~没错我是苦逼初三生了哈哈~~）

博客真的是一个很让人 **沉迷** 的东西，也是这几年我没事干就会想要折腾的项目。人生不就是在不断地折腾嘛，所以……

**我更新了它！**（毫不意外嘛）

## 背景

所以为什么我要更新它？这次我确实是有事情干，趁着做 MexyLaziness 学习 Flutter 嘛。我在做这个博客主题时候甚至是多线程工作的，OpenCode 开了两个会话……大概如此，这个周末很疯狂。不过大肥鱼也确实惊艳到我了，一个看起来不咋简单的博客花了 ￥12- 就弄完了，这么强？！

回到正题。你可能会注意到我以前使用的是 Shirone：一个基于 Astro 框架与 Fuwari 的 M3E 主题。

它用着其实并没什么问题，实际上它的功能是我试过的博客中功能最多最丰富的一个，但是它的问题也出在其中：

**它太复杂了。**抛开我是 P 人以及我有~~疑病症怀疑自己是 ADHD 的受害者导致我一整天耗在书房里只写了一张卷子~~的原因之外，还有很多功能我也用不到：~~我真的要把我可怜的设备数量写在里面让别人觉得我很可怜施舍我点投啃吗？~~

实话说它的设计其实挺好的，但也只是挺好的，我看不出它 *Expressive* 在哪。Material 3，确实有风味，好看，但称不上 M3E：我心目中的 M3E 应该是那种形状丰富，大按钮多变动画的那种。Shirone 太过平淡了，除了配色外就是个标准的 MD3 外观。

所以我构建了它！M33E 主题。~~其实要我说，它也不怎么 Expressive，还有很多小毛病……但毕竟是我使唤大肥鱼写的口牙！~~

## 构建

其实我说我是 AI 偏向保守的那一块你信吗。

你说对了，我从来没用 Vibe Coding 完整构建过一个 App，所以这算是初见，大概吧……？

于是，**我写 Prompt！**我先向网页版 DS 许愿让它给我一个完整的提示词，稍加修改便直接丢进 OpenCode 里面 Build 了。当时我一边等它构建完一边修 Flutter Android 模拟器调试问题，~~确实是脑裂的一环？~~

DS4.1F 确实是适合许愿式编程。VitePress 我实际上并不熟悉，我可以说我对所有现代 Web 技术都不熟悉，~~骗你的桌面移动也一样~~。跑一次实际上就已经大成功了，除了一些小修小补外其实真的是可以直接上线的程度。npm 分发我懒得做了，于是……

你看到了 https://github.com/unnuTechnology/M33EBlog ！（记得点个 Star）
