# CyIME 很好，但也不好

我要先下一个暴论，那就是没有一个基于 Rime 的（安卓）输入法能做平衡性。

这是真的。想想看市面上的 Android Rime 输入法：

- **Fcitx5** 很好的输入法，但是它太单薄了。连语音输入我都没正常用过，虽然我没有语音输入的需求（完全手打党一枚），但是很明显 Feature 太少了。
- **Fcitx5.fx** Fcitx5 2 开，虽然说它增加了许多额外功能（~~其实也没那么多~~），比如自定义任何键位（你知道这有多酷吗，我可以手搓一个电脑同款那种带上 Tab、CapsLock 的键盘，就像 iPad），但是它仍然没有解决 Fcitx5 Based 的核心问题：它只能输入。
- **CyIME** 今天我想讲的，应该是基于 Xime 的输入法。Xime 我没用过，但开发者确实做了很多基础工作，而且 CyIME 风评也很不错，所以……

我尝试了它。以下，是我的使用报告。

## 初步体验

我必须先说明一下，我在 B 站上看到这玩意儿的宣传片时，Like bro wtf 这是一个长达十几分钟仅仅打字的视频。

我理解作者为什么要这样干，不过顺带夸一声，降低完播率的好方法啊兄弟。你用 PPT 用得好我都不会说什么（Ref：SecRandom 2 宣传片）。不过本着试试的原则，我还是使用了它，然后我就被 AI
 文风……淹死了。

**我在这里恳求各位，你全 Vibe 我都不说什么，别拿 AI 写文案行吗。** _**算我求你了。**_

抛去 Vibe 不谈，其实它做的功能真的很多，而且可用性也不低。现阶段如果不是还没踏进正式版，我会把它作为入门 Rime 的第一顺位。它有语音输入，有手写，甚至有滑行输入，虽然现阶段体验还没有优化好，但这功能的丰富程度至少是闭比上国内众多其他输入法厂商了。

但接下来就到痛点了。

## 我为什么不喜欢它

这段标题很奇怪，其实我喜欢它。它有不错的 UI 设计，有很好的响应速度，上下符号更是最令我惊喜的 Part，终于不用翻符号列表找我最爱用的「」方引号了。

但是，它也不好，而且不好地太突出了。

首先，用过 Rime 的都知道，Rime 的核心是它的方案，也就是一堆 yaml 文件，加上用户自定义的 custom 补丁文件，我们可以在别人打好的地基上最大程度地自定义属于自己的输入法。

但是在 CyIME 我甚至得到它专门的入口用它那个并不算得上是「好用」的文件管理器，去管理庞大的 Rime 用户文件夹。而我在 Fcitx5 Based 怎么做呢？我打开 MT 管理器，进入 Android/data/org.xxx/data/rime，然后直接就能管理它，编辑完重新部署一下就好了。「重新部署」这么重要的功能我甚至在 CyIME 只能在它设置的一角看到一个按钮，此外别无他物。

Rime 最核心的东西被抛弃了，这在我看来是不应该的。我日用的词库是「白霜拼音」，而 CyIME 只有雾凇拼音。这意味着我需要导入配置文件……

最好笑的来了，CyIME 只支持导入 zip，即使在同一台机子上。有什么心事吗。

以上即是它最重要的问题。其他问题，像是我的另一个罗马字方案变成滚木了、Switches 也变成滚木了，也很重要，但没那个重要，所以我暂时按下不表。

## 为什么 Rime 起不来

以下是我想探讨的最核心的问题。

**为什么 Rime 在我们看来大多数时候都很完美了但还是敌不过商业输入法？**

答案其实很简单。因为它是 Rime。

Rime 的架构决定了它始终是面向 Dev 和 Geek 这样的少数玩家的。大众只想要一个开箱即用的环境，Rime。很明显给不了，至少自带的朙月拼音要按 Ctrl Grave 切换方案和对普通用户如同天书一般的 yaml 配置给不了。

所以，这就注定了像 Xime CyIME 最终大概率都是失败的，它们试图在大众需求和 Geek 需求中取得平衡，最终只能是两边都不讨好：Geek 不喜欢它的定制程度、而对于大众来说，「我只是想打字」。我给 CyIME 开了俩单子，现在还没回——虽然说只过了一两天吧，作为同样写过点东西的人我能理解。

问题到此为止，接下来我阐述个客观事实。

CyIME 简介中批判了「Vibe 过度的 Rime」输入法。

而 CyIME，至少从一个 Issue 中 Claude Code 自报家门回复和它的风味文本来看，很明显也是 Vibe 的。至于过不过度，诸位自己评判。

考完试见。
